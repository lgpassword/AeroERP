# AeroERP.Modules.Inventory 模块说明

## 模块作用

库存模块负责采购入库、销售出库、仓间调拨、库存盘点、库位、库存余额、库存流水和加权平均成本，是 ERP 数量和金额库存的核心执行层。

## 目录内容

- `Domain/`：入库、出库、调拨、盘点、流水、库存余额和库位实体。
- `Contracts/`：库存执行、查询和成本相关 DTO。
- `Services/`：库存服务接口。
- `Endpoints/`：库存 HTTP API 映射。

## 整体链路

采购订单下达后进入待入库，入库增加库存余额和库存流水。销售订单待出库时由库存模块扣减库存。调拨和盘点同步影响余额与流水。财务和制造读取库存动作形成成本和业务来源。

## 审查重点

- 所有库存动作必须同步数量、单位成本、发生金额和结存金额。
- 出库、调拨出库、生产领料和外协发料应按移动加权平均成本出库。
- 库位库存和仓库库存要保持一致性。
