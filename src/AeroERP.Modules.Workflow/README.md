# AeroERP.Modules.Workflow 模块说明

## 模块作用

工作流模块管理流程定义、流程实例、审批任务和通知，当前用于支撑采购申请审批和审批中心。

## 目录内容

- `Domain/`：流程定义、实例、审批任务、通知和状态常量。
- `Contracts/`：工作流列表、处理和通知 DTO。
- `Services/`：工作流服务接口。
- `Endpoints/`：工作流 HTTP API 映射。

## 整体链路

业务模块提交需要审批的事项后，工作流模块创建实例和待办。审批人在前端处理任务，结果回写业务状态并产生通知。

## 审查重点

- 审批任务状态和业务状态必须同步。
- 通知不能代替业务状态变更。
- 工作流定义应可追溯，不应隐藏审批来源。
