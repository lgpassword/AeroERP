# AeroERP.Modules.AdvancedManufacturing 模块说明

## 模块作用

高级制造模块扩展基础制造能力，覆盖工作中心、工艺路线、工序计划、产能占用、成本快照和 MRP 建议。

## 目录内容

- `Domain/`：工作中心、工艺路线、工序、工序计划、产能负载、成本快照和 MRP 建议。
- `Contracts/`：高级制造看板和执行 DTO。
- `Services/`：高级制造服务接口。
- `Endpoints/`：高级制造 HTTP API 映射。

## 整体链路

基础制造提供工单和成本来源，高级制造在此基础上管理工艺和产能，生成计划建议与成本快照，供生产计划和管理分析使用。

## 审查重点

- 工艺路线和工序计划要能回到具体工作中心。
- 产能占用不能脱离真实工单或计划来源。
- 成本快照应保留生成时间和来源口径。
