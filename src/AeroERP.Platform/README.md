# AeroERP.Platform 模块说明

## 模块作用

`AeroERP.Platform` 定义平台层的领域对象、DTO、权限常量和服务接口，是身份、权限、组织、模块可见性、审计和智能体审查治理的业务契约层。

## 目录内容

- `Domain/`：用户、角色、组织、模块可见性、权限、审计和智能体审查领域模型。
- `Contracts/`：平台 API 输入输出 DTO。
- `Services/`：平台服务接口和当前用户扩展方法。

## 整体链路

AppHost 暴露平台 API，基础设施服务实现 `Services/` 中的接口，领域对象通过 EF Core 持久化。前端平台页读取这些 API 进行账号、角色、模块和审计治理。

## 审查重点

- 权限常量必须和前端权限判断保持一致。
- 智能体审查相关模型必须保留审查人、决策、时间和状态，不能默认自动批准。
- 平台契约层不应依赖基础设施实现。
