# AeroERP.Modules.Control 模块说明

## 模块作用

管控模块提供经营统计、数据范围规则、角色选项和单据编号规则，是平台治理和业务可视化的辅助模块。

## 目录内容

- `Domain/`：数据范围规则、编号规则、单据类型和范围类型。
- `Contracts/`：统计、数据范围和编号规则 DTO。
- `Services/`：管控服务和编号服务接口。
- `Endpoints/`：管控 HTTP API 映射。

## 整体链路

业务服务创建单据时通过编号服务生成业务编号。平台或管控页面维护数据范围规则，经营统计从真实业务数据聚合生成。

## 审查重点

- 编号规则要保证同一单据类型下的唯一性和可读性。
- 数据范围规则要和角色、权限、组织关系保持一致。
- 统计不能使用演示数据，必须基于持久化业务数据。
