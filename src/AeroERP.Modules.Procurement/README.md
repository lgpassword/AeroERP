# AeroERP.Modules.Procurement 模块说明

## 模块作用

采购模块管理从采购申请、审批通过、生成采购订单到订单下达的闭环，是库存入库和应付形成的上游来源。

## 目录内容

- `Domain/`：采购申请、申请行、采购订单和采购状态。
- `Contracts/`：采购申请、审核、转单和下达相关 DTO。
- `Services/`：采购服务接口。
- `Endpoints/`：采购 HTTP API 映射。

## 整体链路

采购申请创建后进入审核，审核通过后可生成采购订单。订单下达后进入库存模块形成待入库来源，采购入库后再进入财务模块形成应付候选。

## 审查重点

- 状态转换必须按申请、审核、订单、下达顺序推进。
- 采购订单不能绕过审批来源。
- 已下达订单要能被库存入库闭环消费。
