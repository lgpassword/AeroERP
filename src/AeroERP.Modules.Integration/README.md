# AeroERP.Modules.Integration 模块说明

## 模块作用

集成模块管理消息通道、外部连接器、同步任务、Webhook 订阅和集成审计，为外部系统对接提供基础能力。

## 目录内容

- `Domain/`：连接器、消息通道、同步任务、Webhook、审计记录和状态。
- `Contracts/`：集成看板、配置和任务 DTO。
- `Services/`：集成服务接口。
- `Endpoints/`：集成 HTTP API 映射。

## 整体链路

平台或业务模块配置外部连接器后，集成任务按通道同步数据或发送 Webhook。每次执行都应写入集成审计，便于排查外部系统问题。

## 审查重点

- 外部连接器配置不能泄露密钥。
- 同步任务要记录状态、时间和错误信息。
- Webhook 需要重试和审计策略，不能静默失败。
