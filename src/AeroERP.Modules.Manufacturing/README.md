# AeroERP.Modules.Manufacturing 模块说明

## 模块作用

制造模块负责 BOM、工单、生产领料、完工入库和基础制造成本归集，是库存原料到成品库存的生产闭环。

## 目录内容

- `Domain/`：BOM、BOM 行、工单、工单用料、生产领料、完工入库和状态。
- `Contracts/`：制造查询、领料、完工和成本 DTO。
- `Services/`：制造服务接口。
- `Endpoints/`：制造 HTTP API 映射。

## 整体链路

用户维护 BOM 后创建工单。工单生产领料会扣减原料库存并归集材料成本。完工入库按工单成本增加成品库存，并形成库存流水和成本拆分。

## 审查重点

- 生产领料必须和库存扣减一致。
- 完工入库的单位成本、材料、人工、机时、制造费用要可追溯。
- 工单状态不能跳过领料和完工业务校验。
