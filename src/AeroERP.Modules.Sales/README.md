# AeroERP.Modules.Sales 模块说明

## 模块作用

销售模块管理客户报价、销售订单和发货前的销售业务状态，是库存出库和应收形成的上游来源。

## 目录内容

- `Domain/`：销售报价、销售订单、销售行和销售状态。
- `Contracts/`：报价、订单和状态推进 DTO。
- `Services/`：销售服务接口。
- `Endpoints/`：销售 HTTP API 映射。

## 整体链路

销售报价被确认后生成销售订单。销售订单进入库存模块执行出库，出库完成后进入财务模块形成应收候选。

## 审查重点

- 报价、订单和出库之间要保持来源关系。
- 销售出库前应保留真实客户、物料、数量和价格。
- 销售模块不直接扣减库存，库存动作由库存模块负责。
