# AeroERP.Modules.Wms 模块说明

## 模块作用

WMS 模块管理上架、拣货、波次、容器、库内路径和 PDA 队列，补齐库存模块之外的仓储执行深度。

## 目录内容

- `Domain/`：上架任务、拣货任务、波次、容器、路径、PDA 队列和状态。
- `Contracts/`：WMS 看板、任务和执行 DTO。
- `Services/`：WMS 服务接口。
- `Endpoints/`：WMS HTTP API 映射。

## 整体链路

库存入库和出库形成仓储执行需求，WMS 负责细化为上架、拣货、波次和 PDA 任务。执行结果应回到库存或业务状态。

## 审查重点

- 仓储任务状态必须可追踪，不应只有看板数据。
- PDA 队列要有明确来源和执行结果。
- WMS 不应重复实现库存余额规则。
