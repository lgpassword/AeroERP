# AeroERP.Modules.DocumentExchange 模块说明

## 模块作用

文档交换模块管理导入模板、字段映射、导入批次、导出任务、打印模板、打印任务和文件审计。

## 目录内容

- `Domain/`：导入模板、字段映射、导入批次、导出任务、打印模板、打印任务和文件审计。
- `Contracts/`：导入导出、打印和审计 DTO。
- `Services/`：文档交换服务接口。
- `Endpoints/`：文档交换 HTTP API 映射。

## 整体链路

用户配置导入模板和字段映射后创建导入批次，系统记录文件处理状态。导出和打印任务产生可追踪文件，并写入文件审计。

## 审查重点

- 文件任务必须有状态、操作者、时间和错误信息。
- 字段映射要避免把无效数据直接写入业务表。
- 文件审计应能追踪导入、导出和打印来源。
