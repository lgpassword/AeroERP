# AeroERP.BuildingBlocks 模块说明

## 模块作用

`AeroERP.BuildingBlocks` 保存跨模块共享的低层基础能力，包括领域实体基类、聚合根标记、模块描述、插件描述和通用操作结果。

## 目录内容

- `Domain/`：实体基类和聚合根标记接口。
- `Abstractions/`：模块、插件和插件表结构初始化的抽象。
- `Results/`：统一的业务操作返回模型。

## 整体链路

业务模块中的领域对象继承 `Entity`，聚合根实现 `IAggregateRoot`。AppHost 和平台基础设施通过模块/插件描述识别系统能力，并通过初始化接口创建插件相关表结构。

## 审查重点

- 这里的代码必须保持稳定、低耦合，不应引用任何具体业务模块。
- 新增抽象前应确认多个模块真实需要，避免把业务细节上移到基础层。
