# AeroERP.Modules.MobileWork 模块说明

## 模块作用

移动作业模块管理移动设备、离线任务、扫码事件和移动工作队列，为仓储、生产和现场作业提供移动端执行记录。

## 目录内容

- `Domain/`：移动设备、离线任务、扫码事件和移动作业状态。
- `Contracts/`：移动作业看板、任务和扫码 DTO。
- `Services/`：移动作业服务接口。
- `Endpoints/`：移动作业 HTTP API 映射。

## 整体链路

业务模块产生需要移动执行的任务，移动作业模块下发或缓存任务，扫码后记录事件并回传执行结果。

## 审查重点

- 离线任务要能识别设备、操作者和同步状态。
- 扫码事件要保留来源、动作、结果和时间。
- 移动作业不能绕过原业务模块的权限和状态校验。
