# AeroERP.Modules.Planning 模块说明

## 模块作用

计划模块负责补货建议、外协加工、条码执行和计划执行历史，用于连接库存、采购、制造和移动作业。

## 目录内容

- `Domain/`：补货建议、外协订单、外协用料、条码执行和状态。
- `Contracts/`：计划建议、外协和扫码 DTO。
- `Services/`：计划服务接口。
- `Endpoints/`：计划 HTTP API 映射。

## 整体链路

系统基于库存余额生成补货建议。外协订单执行发料和收料，条码执行记录 PDA 或扫码动作结果。相关动作应回到库存和业务状态。

## 审查重点

- 补货建议要基于真实仓库、物料和库存余额。
- 外协发料/收料要有数量、物料和状态校验。
- 条码执行记录必须保存动作、结果、操作者和时间。
