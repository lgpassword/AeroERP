# AeroERP.Modules.Quality 模块说明

## 模块作用

质量模块管理质检记录、质检结果、质量单据类型和批次追溯事件，用于追踪采购、制造、销售等来源的质量链路。

## 目录内容

- `Domain/`：质检记录、质检结果、批次事件、批次事件类型和质量单据类型。
- `Contracts/`：质检候选、质检记录和追溯 DTO。
- `Services/`：质量服务接口。
- `Endpoints/`：质量 HTTP API 映射。

## 整体链路

采购入库、完工入库和销售出库可形成质检来源。质检结果写入质量记录，并按批次号形成追溯事件，供前端查询完整追溯链。

## 审查重点

- 质检来源必须指向真实业务单据。
- 批次事件要包含方向、来源、物料和时间。
- 质量模块不能伪造库存或制造状态。
