# AeroERP.Modules.Finance 模块说明

## 模块作用

财务模块负责会计科目、会计期间、总账凭证、应付、应收、税票、银行账户、银行流水、结算对账和基础财务报表。

## 目录内容

- `Domain/`：会计科目、期间、凭证、应付、应收、税票、银行、结算等领域对象。
- `Contracts/`：财务单据、账龄、报表和结算 DTO。
- `Services/`：财务服务接口。
- `Endpoints/`：财务 HTTP API 映射。

## 整体链路

采购入库或采购订单形成应付来源，销售出库或销售订单形成应收来源。财务模块生成业务凭证、登记税票、执行付款/收款结算，并输出试算平衡、利润表和资产负债表基础快照。

## 审查重点

- 来源单据要防重，不能重复生成应收、应付或凭证。
- 期间关账后应限制业务重算和凭证修改。
- 借贷平衡、价税拆分和结算余额是核心审查点。
