# AeroERP.Modules.Localization 模块说明

## 模块作用

本地化模块管理币种、税票基础设置、本地化内容和组织设置，为财务、采购、销售和多组织场景提供基础配置。

## 目录内容

- `Domain/`：币种、本地化内容和本地化设置。
- `Contracts/`：币种、税票、组织本地化 DTO。
- `Services/`：本地化服务接口。
- `Endpoints/`：本地化 HTTP API 映射。

## 整体链路

平台组织和财务业务读取本地化设置，前端通过本地化页面维护币种、税票类型、税率和发票抬头等基础信息。

## 审查重点

- 默认币种和税率要与财务单据兼容。
- 组织设置不能破坏已有单据的历史口径。
- 本地化内容应可扩展，但不应覆盖业务规则。
