# AeroERP.Modules.MasterData 模块说明

## 模块作用

主数据模块维护 ERP 的基础经营对象：客户、供应商、物料和仓库。其他模块通过主数据获取业务单据所需的基础引用。

## 目录内容

- `Domain/`：客户、供应商、物料、仓库实体。
- `Contracts/`：主数据查询、创建和更新 DTO。
- `Services/`：主数据服务接口。
- `Endpoints/`：主数据 HTTP API 映射。

## 整体链路

用户在前端主数据页维护基础资料。采购使用供应商和物料，销售使用客户和物料，库存使用物料和仓库，制造和计划也依赖物料与仓库。

## 审查重点

- 启停状态要影响后续业务选择，但不能破坏历史单据。
- 编码、名称和启用状态是跨模块引用的关键字段。
- 主数据模块不应反向依赖采购、销售、库存或制造模块。
