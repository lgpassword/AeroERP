# AeroERP.Modules.Reporting 模块说明

## 模块作用

报表模块管理报表定义、运行记录、导出任务和报表状态，为经营分析和业务审计提供报表执行历史。

## 目录内容

- `Domain/`：报表定义、运行记录、导出任务和状态。
- `Contracts/`：报表看板、运行结果和导出 DTO。
- `Services/`：报表服务接口。
- `Endpoints/`：报表 HTTP API 映射。

## 整体链路

报表定义指定报表类型和数据口径，运行记录保存实际执行结果，导出任务生成文件并保留状态。

## 审查重点

- 报表数据必须来自真实业务聚合。
- 报表定义和运行结果要能区分，避免覆盖历史口径。
- 导出任务要保留状态和错误信息。
