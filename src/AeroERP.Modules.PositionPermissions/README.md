# AeroERP.Modules.PositionPermissions 模块说明

## 模块作用

岗位权限模块管理岗位、部门、权限包、角色授权、岗位角色绑定和岗位数据范围，用于细化平台角色之外的组织权限。

## 目录内容

- `Domain/`：岗位、部门、权限包、角色授权、岗位绑定和数据范围规则。
- `Contracts/`：岗位权限总览、维护和绑定 DTO。
- `Services/`：岗位权限服务接口。
- `Endpoints/`：岗位权限 HTTP API 映射。

## 整体链路

平台角色提供基础权限，岗位权限模块进一步按岗位、部门和数据范围细化访问控制。前端岗位权限页展示配置结果。

## 审查重点

- 权限包、角色授权和岗位绑定不能互相矛盾。
- 数据范围应可审计，不能绕过平台权限。
- 岗位变更要避免破坏历史审批和审计记录。
