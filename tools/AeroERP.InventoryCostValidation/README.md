# AeroERP.InventoryCostValidation 工具说明

## 模块作用

该工具用于验证库存成本和制造成本链路，覆盖采购入库单位成本、库存加权平均、生产领料、完工入库和成本拆分。

## 目录内容

- `Program.cs`：构造库存和制造验证场景，调用库存/制造服务，输出成本结果。
- `AeroERP.InventoryCostValidation.csproj`：验证工具项目文件。

## 整体链路

工具创建隔离数据，执行采购入库、生产领料和完工入库，验证材料、人工、机时、制造费用、单位成本和库存流水金额是否一致。

## 审查重点

- 成本验证应覆盖数量、单位成本、发生金额和结存金额。
- 制造成本拆分变化后必须同步更新验证工具。
