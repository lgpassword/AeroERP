# AeroERP.FinanceReportValidation 工具说明

## 模块作用

该工具用于验证财务报表口径和财务服务计算链路，帮助在不依赖前端操作的情况下检查试算平衡、利润表和资产负债表等结果。

## 目录内容

- `Program.cs`：构造验证场景、调用服务、输出验证结果。
- `AeroERP.FinanceReportValidation.csproj`：验证工具项目文件。

## 整体链路

工具启动后准备隔离数据环境，调用财务服务生成报表快照，并检查关键金额与平衡关系。

## 审查重点

- 验证数据应只服务于工具本身，不能进入用户界面。
- 财务口径变化后必须同步更新验证断言。
