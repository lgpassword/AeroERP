# AeroERP 操作文档

本文面向首次使用、项目评审和后续接手维护的人，按页面说明 AeroERP 的主要模块、界面区域、可执行操作、权限状态和业务衔接。

## 1. 运行入口

### 后端

在仓库根目录执行：

```powershell
.\scripts\start-apphost-single.ps1 -StopExisting
```

默认地址：

- API：`http://localhost:5099/api`
- Swagger：`http://localhost:5099/swagger`

### 前端

在仓库根目录执行：

```powershell
npm install
npm run dev --workspace @aeroerp/web -- --host 0.0.0.0 --port 5173
```

默认地址：

- Web 工作台：`http://localhost:5173`

### 默认账号

```text
账号：admin
密码：Admin@123456
```

## 2. 页面通用约定

- 所有业务页面都读取真实持久化数据，没有业务演示假数据。
- 没有数据时，页面显示明确空状态和下一步建议。
- 没有权限时，页面隐藏不可执行按钮，或显示只读说明。
- 隐藏模块不会出现在左侧导航、工作台模块入口和路由访问中。
- 表单提交失败时会显示校验提示；成功时会刷新当前列表或显示成功消息。
- 页面中的刷新按钮用于重新读取后端真实状态。

## 3. 登录页

入口：`/login`

页面作用：

- 输入账号和密码进入系统。
- 展示默认初始化账号，方便本地启动后快速进入。

主要区域：

- 品牌区：展示 AeroERP 标识和产品定位。
- 登录表单：账号、密码、进入系统按钮。
- 默认账号提示：显示 `admin` 和 `Admin@123456`。

操作方式：

1. 输入账号。
2. 输入密码。
3. 点击“进入系统”。
4. 登录成功后进入工作台。

异常状态：

- 密码错误或账号停用时，页面显示登录失败信息。
- 后端未启动时，登录请求无法完成，需要先启动 AppHost。

## 4. 工作台

入口：`/workspace`

页面作用：

- 作为登录后的总览页。
- 展示当前账号可见模块、权限数量、角色数量和业务链路覆盖情况。
- 提供所有授权模块的卡片入口。

主要区域：

- 顶部状态：当前工作区名称、已加载模块数、权限数量。
- 总览卡片：可见模块、权限数量、角色数量、未接入路由数量。
- 模块分布：按组织与人员、业务主线、执行现场、财务与报表、集成插件、平台治理分组。
- 闭环链路：基础资料、采购来源、库存执行、财务结算、经营报表。
- 模块入口：点击进入具体业务页面。

操作方式：

1. 登录后先查看工作台确认当前账号权限。
2. 通过左侧导航或模块入口进入业务页面。
3. 如果缺少模块入口，回到平台治理检查角色和模块显隐。

## 5. 平台治理

入口：`/platform`

页面作用：

- 管理账号、角色、模块可见性、组织、审计事件和智能体审查。
- 是系统权限和治理的核心入口。

主要区域：

- 用户管理：展示用户、角色、启用状态，支持创建用户、分配角色、启停账号、重置密码。
- 角色与模块：展示角色可访问的模块，支持调整模块授权。
- 组织管理：维护组织名称、默认角色和地区编码。
- 智能体审查：提交智能体动作审查，执行审批或拒绝。
- 审计事件：展示平台治理相关审计记录。

常用操作：

1. 创建组织。
2. 创建账号并设置初始密码。
3. 给账号分配角色。
4. 根据角色调整模块可见性。
5. 检查审计事件确认关键操作被记录。

权限影响：

- 没有用户管理权限时，无法创建、停用或重置账号。
- 没有模块管理权限时，无法调整模块显隐。
- 没有审查权限时，只能查看或提交审查请求，不能最终批准。

业务衔接：

- 平台治理决定所有模块页面能否访问。
- 角色权限决定按钮是否可见。
- 智能体动作必须先进入审查流程，不能默认自动批准。

## 6. 组织协同

入口：`/organization-collaboration`

页面作用：

- 提供组织、部门和人员之间的协同消息能力。
- 支持会话、消息、附件和已读状态。

主要区域：

- 联系人列表：来自平台用户和组织人员数据。
- 会话列表：展示直接会话和未读状态。
- 消息线程：展示双方消息、发送人、时间和附件。
- 消息输入：输入文本、上传附件并发送。

操作方式：

1. 在联系人列表选择人员。
2. 创建或打开直接会话。
3. 输入消息内容。
4. 可附加文件后发送。
5. 阅读消息后系统更新已读状态。

空状态：

- 没有人员联系人时，先到人员管理创建员工账号。
- 没有会话时，选择联系人发起会话。

## 7. 人员管理

入口：`/people-management`

页面作用：

- 管理员工账号、入职建档、组织归属和部门岗位结构。
- 将平台账号和人员管理页面打通。

主要区域：

- 员工账号：展示真实平台账号、登录名、角色和启用状态。
- 入职建档：创建新员工登录账号，填写账号、姓名、初始密码、角色权限和登录状态。
- 组织归属：展示平台组织清单。
- 部门岗位架构：展示岗位权限模块中的部门和岗位。
- 落地边界：说明账号入职、岗位归属和组织归属的接入状态。

操作方式：

1. 填写登录账号。
2. 填写员工姓名。
3. 设置初始密码。
4. 使用角色按钮选择一个或多个角色。
5. 选择“允许登录”或“暂不启用”。
6. 点击“创建员工账号”。

权限影响：

- 没有用户读取权限时，不能查看员工账号。
- 没有用户维护权限时，不能创建员工账号。
- 没有岗位读取权限时，部门岗位架构显示权限缺失说明。

业务衔接：

- 新员工账号可立即用于登录。
- 角色决定后续可见模块和可操作按钮。
- 员工与组织、岗位的强绑定需要员工档案表继续闭环。

## 8. 插件中心

入口：`/plugin-center`

页面作用：

- 展示插件分组、模块显隐、模块入口和系统扩展状态。

主要区域：

- 插件分组：按平台治理、业务主线、执行现场、财务与报表、集成插件等分组。
- 模块卡片：展示模块名称、说明、显隐状态和入口。
- 可见性状态：显示模块是否对当前账号可见。

操作方式：

1. 查看各插件模块是否已启用。
2. 点击模块入口进入页面。
3. 如需调整显隐，进入平台治理处理模块授权。

业务衔接：

- 插件显隐会影响导航和工作台入口。
- 隐藏模块不会破坏已有持久化数据。

## 9. 主数据

入口：`/master-data`

页面作用：

- 维护客户、供应商、物料和仓库。
- 是采购、销售、库存、制造、财务链路的基础。

主要区域：

- 客户：客户编码、名称、联系人、电话、组织、币种、税号和发票抬头。
- 供应商：供应商编码、名称、联系人、电话、组织、币种、税号和发票抬头。
- 物料：物料编码、名称、单位、启用状态。
- 仓库：仓库编码、名称、地点、组织和启用状态。

操作方式：

1. 先创建客户和供应商。
2. 创建物料并设置单位。
3. 创建仓库。
4. 后续采购、销售、库存和制造页面会引用这些资料。

权限影响：

- 只有读取权限时，只能查看列表。
- 有维护权限时，才能创建和更新基础资料。

业务衔接：

- 采购申请需要供应商和物料。
- 销售报价需要客户和物料。
- 库存入库、出库、调拨和盘点需要仓库和物料。

## 10. 客户 CRM

入口：`/crm`

页面作用：

- 汇总客户、报价和订单管道。
- 帮助从客户视角查看销售推进状态。

主要区域：

- 客户卡片：展示客户基础信息和状态。
- 报价管道：展示销售报价阶段。
- 订单管道：展示销售订单阶段和待发货状态。
- 指标区：汇总客户、报价、订单和执行状态。

操作方式：

1. 先在主数据维护客户。
2. 在销售管理创建报价和订单。
3. 回到 CRM 查看客户维度的报价和订单进展。

业务衔接：

- CRM 不替代销售单据创建，主要用于客户视角总览。
- 报价和订单状态来自销售管理模块。

## 11. 采购管理

入口：`/procurement`

页面作用：

- 管理采购申请、审核、采购订单转换和订单下达。

主要区域：

- 采购申请表单：选择供应商、填写标题、币种、税票类型、税率和物料行。
- 采购申请列表：展示申请状态、行项目和审核操作。
- 采购订单列表：展示由申请转换而来的订单。
- 订单动作：转单、下达、进入库存入库。

操作方式：

1. 在主数据准备供应商和物料。
2. 创建采购申请。
3. 审核通过申请。
4. 将申请转换为采购订单。
5. 下达采购订单。
6. 到库存管理查看待入库订单并执行入库。

权限影响：

- 没有创建权限时，不能提交采购申请。
- 没有审核权限时，不能审批申请。
- 没有订单权限时，不能转单或下达。

业务衔接：

- 下达后的采购订单进入库存待入库。
- 入库后可进入财务生成应付。

## 12. 销售管理

入口：`/sales`

页面作用：

- 管理销售报价、报价转订单、订单确认和待发货状态。

主要区域：

- 销售报价表单：选择客户、标题、币种、税票类型、税率和物料行。
- 报价列表：展示报价状态和转订单操作。
- 销售订单列表：展示订单状态、确认和待发货动作。

操作方式：

1. 在主数据维护客户和物料。
2. 创建销售报价。
3. 将报价转换为销售订单。
4. 确认销售订单。
5. 标记待发货。
6. 到库存管理执行销售出库。

业务衔接：

- 待发货订单进入库存待出库列表。
- 出库后可进入财务生成应收。

## 13. 库存管理

入口：`/inventory`

页面作用：

- 执行采购入库、销售出库、库存调拨、盘点、库位维护、库存余额、库存流水和存货明细账。

主要区域：

- 待入库采购订单：来自已下达采购订单。
- 待出库销售订单：来自待发货销售订单。
- 入库记录：展示采购入库结果、成本和仓库。
- 出库记录：展示销售出库结果和出库成本。
- 调拨记录：在仓库或库位之间移动库存。
- 盘点记录：按盘点差异调整库存。
- 库位维护：维护仓库下的库位。
- 库存余额：展示仓库级库存。
- 库位余额：展示库位级库存。
- 库存流水：展示入库、出库、调拨、盘点、领料和完工等移动。
- 存货明细账：展示数量、单位成本、发生金额和结存金额。

操作方式：

1. 从待入库采购订单选择仓库和库位，执行入库。
2. 从待出库销售订单选择仓库和库位，执行出库。
3. 需要内部移动时创建调拨。
4. 实物盘点后创建盘点调整。
5. 查看余额、流水和存货明细账确认结果。

业务衔接：

- 采购入库增加库存并形成后续应付来源。
- 销售出库减少库存并形成后续应收来源。
- 制造领料、完工入库、外协发料和外协收料也会写入库存流水。

## 14. WMS 执行

入口：`/wms`

页面作用：

- 管理仓内上架、拣货、波次、容器、路径和 PDA 队列。

主要区域：

- 容器：维护托盘、箱、周转容器等载具。
- 仓内路径：维护库位之间的路径距离和优先级。
- 上架任务：创建并完成上架任务。
- 拣货任务：创建并完成拣货任务。
- 波次任务：组合拣货任务并发布波次。
- PDA 队列：承接移动端或现场作业任务。

操作方式：

1. 先维护仓库和库位。
2. 创建容器和路径。
3. 根据入库或出库需要创建上架/拣货任务。
4. 将拣货任务组合为波次。
5. 发布波次后进入现场执行。

## 15. 移动作业

入口：`/mobile-work`

页面作用：

- 管理移动设备、离线任务、扫码记录和移动作业队列。

主要区域：

- 移动设备：登记设备编码、名称、负责人和启用状态。
- 离线任务：创建、同步和完成离线作业任务。
- 扫码记录：记录设备、条码、目标模块、动作、单号和执行结果。
- 移动队列：展示跨模块移动作业状态。

操作方式：

1. 登记移动设备。
2. 创建离线任务并分配人员。
3. 同步或完成离线任务。
4. 记录扫码事件。
5. 根据执行结果回到对应业务模块处理异常。

## 16. 制造管理

入口：`/manufacturing`

页面作用：

- 管理 BOM、工单、生产领料、完工入库和工单成本。

主要区域：

- BOM：维护成品物料、版本、基准数量和组件用量。
- 工单：基于 BOM 创建生产工单。
- 生产领料：按工单扣减原料库存。
- 完工入库：将成品入库并写入成本。
- 成本信息：展示材料、人工、机时、制造费用、总成本和单位成本。

操作方式：

1. 在主数据维护成品、组件和仓库。
2. 创建 BOM。
3. 创建工单并下达。
4. 执行生产领料。
5. 执行完工入库。
6. 查看工单成本和成品库存成本。

业务衔接：

- 领料会减少原料库存。
- 完工入库会增加成品库存。
- 高级制造成本快照可影响完工成本来源。

## 17. 高级制造

入口：`/advanced-manufacturing`

页面作用：

- 管理工作中心、工艺路线、工序排程、产能负载、成本快照和 MRP 建议。

主要区域：

- 工作中心：维护产能分钟数、小时成本和启用状态。
- 工艺路线：维护成品工艺版本和工序。
- 工序排程：按工单计划工序开始、结束和数量。
- 产能负载：记录工作中心每日可用和占用产能。
- 成本快照：记录工单材料、人工、机时和制造费用。
- MRP 建议：生成并处理物料需求建议。

操作方式：

1. 建立工作中心。
2. 创建并激活工艺路线。
3. 为工单创建工序排程。
4. 维护产能负载。
5. 创建成本快照。
6. 生成并决策 MRP 建议。

业务衔接：

- 成本快照会被制造完工成本优先使用。
- MRP 建议可指导采购、生产和补货。

## 18. 计划执行

入口：`/planning`

页面作用：

- 基于真实仓库、物料和库存余额生成补货建议，管理外协订单和条码执行。

主要区域：

- 补货建议：生成、接受或忽略建议。
- 外协订单：创建外协加工单。
- 外协发料：将材料从库存发给外协方。
- 外协收料：外协完成后收回成品或半成品。
- 条码执行：记录条码动作和执行结果。

操作方式：

1. 选择仓库、物料和最低库存生成补货建议。
2. 对建议做接受或忽略决策。
3. 创建外协订单并配置材料行。
4. 执行外协发料。
5. 外协完成后收料。
6. 使用条码执行记录现场动作。

业务衔接：

- 外协发料和收料会写入库存余额与库存流水。
- 条码执行会保存成功或失败结果。

## 19. 质量追溯

入口：`/quality`

页面作用：

- 基于采购入库、完工入库、销售出库等真实来源创建质检记录和批次追溯事件。

主要区域：

- 来源候选：展示可用于创建质检的真实业务来源。
- 质检记录：记录检验数量、合格数量、不合格数量、处置方式和说明。
- 批次事件：记录批次号、事件类型、来源单据、目标单据和数量。
- 批次追溯查询：按批次号查询完整链路。

操作方式：

1. 从来源候选选择真实来源。
2. 创建质检记录。
3. 创建批次事件。
4. 输入批次号查询追溯链。

业务衔接：

- 质量记录来自真实入库、完工或出库数据。
- 批次事件可连接采购、生产、库存和销售过程。

## 20. 财务结算

入口：`/finance`

页面作用：

- 管理会计科目、会计期间、总账凭证、应付、应收、税票、银行账户、银行流水、结算、对账和财务报表。

主要区域：

- 会计基础：会计科目、会计期间、关账和重开。
- 总账凭证：手工凭证、业务来源凭证、提交、审核通过和驳回。
- 应付应收：从采购入库、采购订单、销售出库和销售订单生成往来记录。
- 税票记录：登记应付/应收来源税票。
- 银行账户：维护账户、币种和启用状态。
- 银行流水：录入收款或付款流水。
- 结算对账：对往来记录进行付款/收款，并和银行流水匹配对账。
- 账龄分析：展示未到期、逾期分桶和明细。
- 财务报表：试算平衡、利润表和资产负债表基础口径。

操作方式：

1. 创建或检查会计科目。
2. 创建会计期间。
3. 从应付、应收或结算生成凭证。
4. 提交并审核凭证。
5. 创建银行账户。
6. 录入银行流水。
7. 对应付或应收执行结算。
8. 执行银行对账。
9. 查看账龄和财务报表。

业务衔接：

- 采购入库和采购订单可生成应付。
- 销售出库和销售订单可生成应收。
- 结算和对账结果会影响财务状态展示。

## 23. 经营管控

业务衔接：

## 29. 推荐业务顺序

首次使用建议按以下顺序操作：

1. 平台治理：检查账号、角色、权限和模块可见性。
2. 主数据：维护客户、供应商、物料和仓库。
3. 本地化：维护币种、税票类型、税率和发票抬头。
4. 采购：创建申请、审核、转订单、下达。
5. 库存：对采购订单执行入库。
6. 销售：创建报价、转订单、确认并标记待发货。
7. 库存：对销售订单执行出库。
8. 财务：从入库、出库、订单和结算生成应付、应收、凭证和报表。
9. 制造：维护 BOM、工单、领料和完工入库。
10. 质量、计划、WMS、移动作业、报表和文档交换按业务需要继续补充。

## 30. 常见问题

### 页面没有按钮

通常是当前账号缺少维护权限。请到平台治理检查角色权限和模块可见性。

### 页面没有数据

AeroERP 不注入业务演示数据。请先按业务顺序创建真实基础资料和业务单据。

### 登录后看不到某个模块

该模块可能被隐藏，或当前账号角色没有该模块权限。请到平台治理调整模块显隐和角色授权。

### 截图不是最新

启动前后端后执行：

```powershell
npm run screenshots
```

截图会更新到 `docs/images/`，README 和截图索引会直接引用这些文件。
