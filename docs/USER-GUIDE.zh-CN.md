# AeroERP 使用说明

本文面向首次运行和审查项目的人，说明 AeroERP 的启动方式、登录方式和主要业务操作链路。

## 1. 启动系统

### 后端

在项目根目录执行：

```powershell
.\scripts\start-apphost-single.ps1 -StopExisting
```

后端默认地址：

- API：`http://localhost:5099/api`
- Swagger：`http://localhost:5099/swagger`

### 前端

在项目根目录执行：

```powershell
npm install
npm run dev --workspace @aeroerp/web -- --host 0.0.0.0 --port 5173
```

浏览器访问：

```text
http://localhost:5173
```

默认登录账号：

```text
账号：admin
密码：Admin@123456
```

## 2. 首次进入后的建议顺序

### 2.1 平台治理

进入“平台治理”后，先检查：

- 当前用户
- 角色和权限
- 可见模块
- 组织资料
- 审计事件
- 智能体审查请求

这个模块决定用户能看到哪些菜单、能执行哪些按钮。

### 2.2 主数据

进入“主数据”，维护业务闭环所需基础资料：

- 供应商
- 客户
- 物料
- 仓库

如果没有这些基础资料，采购、销售、库存和制造流程无法形成真实业务单据。

### 2.3 本地化和组织设置

进入“组织本地化”，检查：

- 币种
- 税票类型
- 税率
- 发票抬头
- 组织默认设置

采购、销售、应收、应付和税票记录会使用这些基础配置。

## 3. 采购到入库链路

推荐操作顺序：

1. 在“采购”创建采购申请。
2. 审核采购申请。
3. 将已审核申请转换为采购订单。
4. 下达采购订单。
5. 在“库存”查看待入库订单。
6. 创建采购入库单。
7. 查看库存余额、库位余额、库存流水和存货明细账。
8. 在“财务”从入库或订单生成应付记录。

这个链路会形成真实持久化数据，不依赖演示数据。

## 4. 销售到出库链路

推荐操作顺序：

1. 在“销售”创建销售报价。
2. 将报价转换为销售订单。
3. 确认销售订单。
4. 标记订单待出库。
5. 在“库存”查看待出库订单。
6. 创建销售出库单。
7. 查看库存余额和出库成本。
8. 在“财务”从出库或订单生成应收记录。

如果库存不足，出库动作会给出校验结果。

## 5. 财务链路

财务模块主要操作顺序：

1. 创建或检查会计科目。
2. 创建会计期间。
3. 从应付、应收或结算生成业务凭证。
4. 提交凭证。
5. 审核通过或驳回凭证。
6. 创建银行账户。
7. 录入银行流水。
8. 对应付或应收进行付款/收款结算。
9. 执行银行对账。
10. 查看账龄、试算平衡、利润表和资产负债表基础口径。

关账前系统会阻止存在草稿或待审凭证的期间直接关闭。

## 6. 制造、计划和 WMS 链路

制造相关建议顺序：

1. 在“制造”维护 BOM。
2. 创建工单。
3. 下达工单。
4. 执行生产领料。
5. 完工入库。
6. 查看工单成本和成品库存成本。

计划执行可基于真实仓库、物料和库存余额生成补货建议，并支持外协发料、外协收料和条码执行记录。

WMS 模块可维护容器、路径、上架任务、拣货任务和波次任务，用于承接更细的仓内执行。

## 7. 审批、通知和质量追溯

- “审批中心”处理采购申请等流程待办。
- “通知”显示工作流通知状态。
- “质量追溯”从采购入库、完工入库、销售出库等真实来源创建质检记录和批次事件。
- 批次追溯查询会按批次号展示完整事件链。

## 8. 权限和模块可见性

AeroERP 的页面和按钮会根据当前账号权限动态显示：

- 无读取权限时，页面不会展示对应业务数据。
- 无维护权限时，按钮会隐藏或展示只读说明。
- 被隐藏模块不会出现在导航和入口。
- 智能体动作必须经过审查和审计，不能默认自动批准。
