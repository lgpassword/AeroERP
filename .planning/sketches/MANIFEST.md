# Sketch Manifest

## Design Direction
面向中文企业运营团队的高密度 ERP 工作台，结合金蝶/用友式业务列表密度、SAP Fiori 式分析区组织、以及 Odoo 式流程入口清晰度。重点不是“卡片化展示”，而是让用户在同一屏内完成查看趋势、筛选异常、打开弹窗处理业务、跳转查看明细的闭环。

## Reference Points
- 金蝶 / 用友：高信息密度、表格优先、业务动作集中
- SAP Fiori：分析图表与对象操作并列
- Odoo：流程节点清晰，适合中小团队快速操作
